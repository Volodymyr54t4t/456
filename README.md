# Письмо для Насти

Адаптивная романтическая страница-признание на русском языке. Вступление просит дочитать письмо, далее идут главы о чувствах, признание в любви и отдельная часть о личных границах и отсутствии ожидания немедленного ответа. Дата знакомства указана как 3 ноября 2026 года.

Открой `index.html` в браузере или размести `index.html`, `styles.css` и `app.js` на статическом хостинге. Ссылка Telegram ведёт на `https://t.me/vovachyzhevskyi`. Серверной части и внешних зависимостей нет.
