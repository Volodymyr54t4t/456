# Письмо для Насти

Адаптивная романтическая страница на русском языке: письмо о знакомстве 3 ноября 2026 года, комплименты-открытки с переворотом и приглашение на прогулку. Поддерживает телефоны, клавиатурное управление и системную настройку уменьшения анимации. Серверной части и зависимостей нет.

Открой `index.html` в браузере или размести `index.html`, `styles.css` и `app.js` на статическом хостинге. Ссылка Telegram ведёт на `https://t.me/vovachyzhevskyi`.
