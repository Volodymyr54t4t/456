# Для Насті

Статична фронтенд-сторінка з вертикальним свайп-фідом, анімаціями та посиланням на Telegram. Серверної частини, збору даних і залежностей немає.

Відкрий `index.html` у браузері або розмісти файли `index.html`, `styles.css` та `app.js` на будь-якому статичному хостингу. Кнопка Telegram веде на `https://t.me/vovachyzhevskyi`.
